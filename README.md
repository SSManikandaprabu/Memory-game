# MemoryMatch - Emoji Memory Matching Game

A colorful, interactive card-flipping memory matching puzzle game with timer, move counter, difficulty levels, and star ratings.

## Features

- Card-flipping grid with animated 3D card rotation physics
- Curated emoji theme deck pairs with randomized shuffle upon each round
- Configurable difficulty tiers (Easy 4x3, Medium 4x4, Hard 6x4)
- Real-time game HUD displaying elapsed time, total flip moves, and current score
- Dynamic 3-star rating algorithm based on move efficiency and speed
- Win celebratory confetti animation using Canvas-Confetti
- High score tracking per difficulty level stored in LocalStorage

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Tailwind CSS
- Canvas-Confetti
- LocalStorage API

## Installation & Setup

This is a standalone, client-side web application. No complex build pipelines, database configurations, or package installations are required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SSManikandaprabu/Memory-game.git
   cd Memory-game
   ```

2. **Run the application:**
   - **Direct Browser Launch**: Double-click `memorymatch_emoji_memory_matching_game.html` to open it directly in any modern web browser (Chrome, Firefox, Safari, Edge).
   - **Or via Local HTTP Server**:
     ```bash
     python -m http.server 8000
     ```
     Then open [http://localhost:8000/memorymatch_emoji_memory_matching_game.html](http://localhost:8000/memorymatch_emoji_memory_matching_game.html) in your browser.

## Usage

1. Launch the application in your browser following the setup instructions above.
2. Interact with the application controls and input fields tailored for MemoryMatch - Emoji Memory Matching Game.
3. Preferences and data are stored locally in your browser's LocalStorage where applicable.
